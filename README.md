# ai-skill

> 将 AI 能力沉淀为标准化技能资产 —— 让原型生成与项目部署从「人工执行」进化为「智能交付」。

## 项目名称

AI Skill 技能集合（ai-skill）

## 项目简介

ai-skill 是一套面向 AI Agent 的**技能资产库**。它以业界通行的 Skill 文档体系为基石，将团队沉淀的工程经验与交付流程，抽象为 AI 可理解、可执行、可复用的标准化技能，让 AI 真正成为研发流水线中的一等公民。

一句话概括：**把「怎么做」写成规范，让 AI 替你「做到」。**

项目核心价值：

- **所见即所得的原型能力** —— 一句需求，AI 即可产出覆盖 PC 管理端、App 移动端与登录页的完整高保真原型，全程遵循统一的设计语言与代码规范，多页面风格零漂移
- **合规专业的文书能力** —— 深度解析招标文件，构建「招标要求 → 投标应答」合规矩阵，逐条点对点应答，产出结构完整、排版统一的投标文件
- **一键直达的交付能力** —— 从前端构建产物的内网 Nginx 发布，到后端系统的测试环境构建与部署，AI 按既定流程自动执行，交付路径最短化
- **敏捷的运营洞察** —— 自动统计任务创建数据，按人、按公司多维聚合，生成日报并推送钉钉，让团队态势一目了然

在工程实现上，所有技能均以纯 markdown 文档承载，仓库零可执行文件，天然保持最低信任等级 —— **安全性与可维护性从架构层面得到保障**，任何 Agent 均可放心加载、即取即用。

## 技能列表

本项目包含以下技能：

- **prototype-generator** —— 原型 HTML 项目生成器
- **bid-document-generator** —— 投标文件生成器
- **sales-project-deploy** —— 销售项目部署
- **zhaocai-test-deploy** —— 集团招采测试环境部署
- **daily-user-task-report** —— 每日用户任务创建汇报

## 技术栈

- **HTML5 / CSS3** —— 语义化标签 + CSS 自定义属性驱动多主题体系
- **Bootstrap 5.3.8 + Bootstrap Icons 1.13.1** —— 组件与图标库（CDN 引入）
- **Vanilla JavaScript** —— ES5 兼容，零依赖、零构建
- **Python + paramiko** —— SFTP 增量同步部署
- **Bash + Gradle + Docker** —— 后端构建与容器化交付
