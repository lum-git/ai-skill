# 投标文件排版格式标准

本文件规定投标文件的**统一排版标准**：页面设置、标题样式、段落样式、编号体系、表格、图表、页眉页脚页码、封面、明标/暗标规则、打印装订。目标是全文视觉一致、专业规范，便于评审专家阅读、定位评分点与横向比较。

> **一句话原则：招标文件的格式条款永远优先；本文件提供招标未规定时的默认标准。**

---

## 一、格式优先级（铁律）

执行任何排版动作前，先按以下优先级取规则：

1. **招标文件（含补遗/答疑）明文格式条款**——逐条执行，包括"投标文件格式"章节的样式规定、**暗标（盲评）细则**
2. 招标文件引用的标准（如"按公文格式排版"→ GB/T 9704-2012）
3. **本文件默认规范**
4. skill 内模板、示例的样式——仅参考，不得覆盖以上任何一级

交付时输出「格式条款对照表」：招标格式条款编号 → 执行情况（照办 / 无规定用默认），纳入自检结果。

---

## 二、标准依据

| 标准 / 文件 | 用途 |
|------------|------|
| GB/T 9704-2012《党政机关公文格式》 | 页面、版心、字体字号的国标基准（现行有效） |
| GB/T 15834-2011《标点符号用法》 | 标点规范 |
| GB/T 15835-2011《出版物上数字用法》 | 数字用法规范 |
| 《标准施工招标文件》（2007 年版）、《房屋建筑和市政工程标准施工招标文件》（2013 年版） | 工程类投标文件格式惯例 |
| 财政部令第 87 号《政府采购货物和服务招标投标管理办法》 | 政府采购响应文件格式惯例 |
| 电子招投标平台投标制作工具的格式限制 | 电子标（尤其暗标）的实际约束 |

---

## 三、明标与暗标：先判定，再排版

**排版前必须先判定本项目是否含暗标（技术标盲评）。**

识别关键词：暗标、盲评、盲审、无标记、不得出现投标人名称、不得含有任何识别投标人身份的信息、隐匿投标人信息、技术标不得做任何标记。

判定为暗标后：**逐字摘录**招标文件中全部格式限制条款，生成「暗标格式核对表」，任何一条不满足即可能导致废标。

### 3.1 暗标常见硬性限制（逐条核对，以招标条款为准）

| 要素 | 常见要求 |
|------|---------|
| 字体 | 中文宋体（GB2312）；部分项目要求全文统一一种字体 |
| 字号 | 正文四号（14pt）或小四（12pt）常规；标题字号按条款执行（常见"宋体三号加粗"或"四号常规"，**两种都有，以条款为准**） |
| 加粗/斜体/下划线/颜色 | 多数暗标禁止（部分项目允许标题加粗）；文字纯黑色 |
| 行距 | 固定值 28~30 磅或单倍行距（条款写哪种用哪种），全文统一 |
| 页眉/页脚/页码 | 通常**严禁设置**（除非条款明示允许） |
| 标识性内容 | 严禁单位名称、Logo、人名、水印、底纹、特殊符号标记、页眉页脚、目录中可识别作者的信息 |
| 标点 | 全中文标点 |
| 图片 | 不得含元数据/拍摄信息；扫描件不得含单位水印 |
| 上传方式 | 按投标制作工具**分章节分段上传**，章节划分须与平台工具一致 |

### 3.2 明标

非暗标部分按第四章起的默认规范执行。

## 四、页面设置

| 要素 | 默认规范 | 说明 |
|------|---------|------|
| 纸张 | A4（210mm×297mm），纵向 | 大型表格/图纸可 A4 横向或 A3，须独立分页并在目录中说明 |
| 页边距 | 上 2.5cm、下 2.5cm、**左 3.0cm（装订侧）**、右 2.5cm | 左侧加宽供装订；招标有规定从其规定 |
| 装订 | 左侧装订（胶装为主） | 禁活页夹（多数项目视为废标风险） |
| 版心参考 | 每页 22~24 行（固定值 28 磅 + 小四字号时） | 对标 GB/T 9704-2012 版心原则（公文版心上 37mm/左 28mm，投标文件按装订与批注需要放宽） |

---

## 五、标题样式

| 级别 | 编号形式（体系 A / 体系 B） | 中文字体 | 字号 | 加粗 | 对齐 | 段前/段后 | 行距 |
|------|---------------------------|---------|------|------|------|----------|------|
| 封面主标题 | — | 方正小标宋或黑体 | 一号（26pt）或二号（22pt） | 加粗 | 居中 | — | 1.5 倍 |
| 一级标题（章） | 第 X 章 / 一、 | 黑体 | 三号（16pt） | 加粗 | 居中 | 24pt / 18pt | 同正文 |
| 二级标题（节） | X.Y / （一） | 黑体或楷体 | 四号（14pt） | 加粗 | 左对齐 | 12pt / 6pt | 同正文 |
| 三级标题 | X.Y.Z / 1. | 仿宋或宋体 | 小四（12pt） | 加粗 | 左对齐 | 6pt / 3pt | 同正文 |
| 四级标题 | （1）/ ① | 同正文 | 同正文 | 加粗 | 左对齐 | 0 | 同正文 |

规则：

1. **编号体系全文统一二选一**：
   - 体系 A（数字层级）：`1 → 1.1 → 1.1.1 → (1) → ① → a)`
   - 体系 B（中文序号）：`一、→（一）→ 1. →（1）→ ①`
   - 招标文件已规定编号形式的，从其规定
2. 标题**独占一行**，行末不加标点；同级标题句式尽量对仗
3. **最多四级标题**；五级及以下用正文加粗引导词，不设标题
4. 暗标项目的标题样式严格按暗标条款覆盖上表

## 六、段落样式

| 元素 | 中文字体 | 西文/数字 | 字号 | 行距 | 段前/段后 | 首行缩进 | 对齐 |
|------|---------|----------|------|------|----------|---------|------|
| 正文 | 宋体或仿宋_GB2312 | Times New Roman | 小四（12pt） | 1.5 倍或固定值 28 磅（全文统一） | 0 / 0 | **2 字符** | 两端对齐 |
| 条款/列表 | 同正文 | 同正文 | 同正文 | 同正文 | 0 | 悬挂缩进（编号对齐） | 两端对齐 |
| 表格内文字 | 宋体 | Times New Roman | 五号（10.5pt） | 单倍 | 3pt | 不缩进 | 文本左对齐、数值右对齐、表头居中 |
| 图表题注 | 黑体或楷体 | 同字号 | 五号 | 单倍 | 6pt / 6pt | 不缩进 | 居中 |
| 落款/签署 | 同正文 | — | 同正文 | 同正文 | 24pt | 不缩进 | 右对齐 |

规则：

1. 首行缩进用"字符"单位（Word：首行缩进 2 字符），**禁止用空格模拟缩进**
2. **段间不插空行**，间距一律用段前/段后值控制
3. 中文语境用全角标点；编号、型号、版本号、小数可用半角
4. 数字用法遵循 GB/T 15835-2011：4 位以上数字加千分位、日期"YYYY 年 MM 月 DD 日"、百分比统一阿拉伯数字

---

## 七、编号与交叉引用

1. 图表编号与章节关联：`表 3-1`（第 3 章第 1 张表）、`图 2-3`（第 2 章第 3 张图），全文连续不重号
2. **表号表题在表格上方居中；图号图题在图片下方居中**
3. 正文引用统一格式："详见第 3.2 节""如表 4-1 所示"；不用"见下表""见上图"
4. 附件编号全文统一（附件一 / 附件 1 二选一），与目录一致

---

## 八、表格规范

1. 表头加粗，可加浅灰底纹（**暗标禁止底纹**）；表头文字居中
2. 跨页表格设置"重复标题行"；关键数据行不跨页断行
3. 单位标注在列头（如"合同金额（万元）"），不在单元格内重复
4. 无内容单元格填"—"，不留空白
5. 列宽保证不折行、不溢出；超宽表格转横向页
6. 招标文件给定表格格式的（报价表、偏离表、开标一览表等），**结构与列名逐字保留，只填内容**

---

## 九、图片与图形

1. 图随文走、先文后图，不出现孤立成页的图
2. 分辨率：打印版 ≥300dpi，电子版 ≥150dpi
3. 架构图、组织架构图、横道图统一配色与线型；须保证**黑白打印仍可辨识**
4. 引用招标文件截图/图纸时注明出处（引自招标文件第 X 页）
5. 图题格式：`图 X-Y 图题`

---

## 十、页眉、页脚与页码

| 场景 | 页眉 | 页脚 |
|------|------|------|
| 明标（商务/技术/报价） | 项目简称 + 册别（宋体小五居中） | 页码"第 X 页 共 X 页"或纯数字（宋体小五居中） |
| 暗标 | **严禁** | **严禁**（含页码） |

- 封面、目录不编页码；正文自第 1 页起连续
- 分册装订时各册独立编页，封面注明"本册共 X 页"
- **目录页码与正文实际页码必须一致**——打印前核对，这是检查中最常出错的地方

---

## 十一、封面规范

要素（自上而下）：

1. 项目名称（**与招标公告逐字一致**）——黑体/方正小标宋，一号或二号加粗居中
2. "投标文件" / "XX 标（册）"字样——宋体一号居中
3. 项目编号、标段/包号——仿宋三号居中
4. 正本/副本标注——右上角或招标指定位置
5. 投标人名称（公章位）+ 法定代表人/授权代表（签字位）+ 日期——宋体三号，居中或右下

招标文件提供封面模板的，**逐字照用**：不加公司 Logo、不调字体字号、不改版式。

---

## 十二、打印、密封与电子版

- 正本 1 份 + 副本按招标份数；正本签字盖章，副本内容与正本一致
- 骑缝章：按要求整本骑缝
- 密封：正副本分装/合装按招标规定；封口骑缝章；袋外标注按招标规定（**匿名评标项目不得标注投标人名称**）
- 电子版（U 盘/平台上传）：与纸质版内容一致；PDF 字体全嵌入、加书签导航、按平台格式限制生成、文件大小按平台要求控制

---

## 十三、Markdown 交付的结构映射

skill 默认输出 Markdown，本标准按以下方式落地：

| 本标准要素 | Markdown 交付时 |
|-----------|----------------|
| 标题层级与编号 | **直接遵守**：`#` 一级（章）→ `##` 二级 → `###` 三级 → `####` 四级 |
| 表格结构、表头、单位、空格填"—" | **直接遵守** |
| 图表编号与题注位置（表上图下） | **直接遵守** |
| 字体、字号、行距、段距、页边距 | Markdown 不承载；转 Word 时用样式模板落地（见下） |

转 Word 命令（样式模板承载全部排版参数）：

```bash
pandoc 投标文件.md -o 投标文件.docx --toc --toc-depth=3 --reference-doc=bid-style.docx
```

> `bid-style.docx` 为按本文件第五章/第六章预设好样式（标题 1~4、正文、表格）的模板。招标提供 Word 模板的，改用招标模板做 reference-doc，或按模板章节顺序组织后粘贴回模板。

## 十四、格式自检清单

- [ ] 明标/暗标已判定；暗标项目「暗标格式核对表」逐条通过
- [ ] 招标格式条款逐条执行，「格式条款对照表」已输出
- [ ] 字体、字号、行距全文统一，无混用；编号体系全文统一
- [ ] 标题层级 ≤4 级；标题独占一行、行末无标点
- [ ] 首行缩进 2 字符（无空格模拟缩进）；段间无空行
- [ ] 表格：表头加粗、跨页重复表头、单位在列头、空格填"—"
- [ ] 图表编号连续、题注位置正确（表上图下）、引用格式统一
- [ ] 页码：封面目录不编、正文连续、目录与正文页码一致
- [ ] 封面要素齐全，项目名称与招标公告逐字一致
- [ ] 正副本、密封、电子版要求已核对
