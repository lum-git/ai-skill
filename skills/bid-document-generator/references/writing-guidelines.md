# 写作规范与自检清单

本文件是投标文件编写的通用规范，适用于两种工作模式。所有生成内容必须遵守。

---

## 一、文档排版规范

### 1.1 标题层级

- 一级标题："第一册 商务标" / "第二册 技术标" / "第三册 报价标"
- 二级标题：章，"1 投标函"
- 三级标题：节，"1.1 报价说明"
- 四级标题："1.1.1 xxx"（必要时用）
- 不超过四级标题

### 1.2 排版格式

完整格式标准（页面设置、标题样式、段落样式、编号体系、表格、图表、页眉页脚页码、封面、明标/暗标规则）统一执行 [format-spec.md](format-spec.md)，本文件不重复规定。

> 招标文件指定排版的，严格按招标要求；未指定时按 format-spec.md 默认规范。Markdown 交付时不控制字体，但标题层级、编号、表格结构、图表题注等结构规范必须遵守。

### 1.3 表格

- 表格统一编号："表 4-1 项目组织架构表"
- 表头加粗
- 跨页表格重复表头
- 列宽合理，文字不溢出
- 表格内信息与正文一致

### 1.4 页码与目录

- 正文连续页码（封面、目录不编或单独编）
- 目录页码与正文一致
- 三册分册时每册独立页码

## 二、语言措辞规范

### 2.1 人称与称谓

- 投标方自称："我方""投标人"（全文统一，不混用"本公司""乙方""我司"）
- 招标方称："采购人""招标人""贵方"（按招标文件用语）
- 不使用"我们""他们"等口语化人称

### 2.2 措辞要求

- **肯定、明确**：用"承诺""保证""完全满足""优于""负责"
- **避免模糊**：不用"尽量""争取""大概""可能""约""左右"描述关键承诺
- **不做比较**：不写"比其他厂商""优于国内同类产品"等无依据对比
- **不贬低他人**：不出现竞争对手名称或影射
- **专业准确**：术语、标准号、规范名称准确无误
- **数字规范**：金额同时写大小写；日期用"YYYY 年 MM 月 DD 日"；百分比用阿拉伯数字

### 2.3 禁用内容

- 与本项目无关的投标方内部信息
- 任何虚假资质、业绩、人员信息（不杜撰，需用户提供）
- 商业秘密、其他客户保密信息
- 违反法律法规、歧视性、排他性表述
- 具体报价金额（除非用户明确给出，否则用占位符）

## 三、点对点应答规则

### 3.1 核心原则

**招标文件的每一条要求，都必须在投标文件中有明确、可定位的应答。** 这是评标专家判断响应性的依据。

### 3.2 应答方式

- **技术参数表**：逐条引用招标参数 → 给出投标参数 → 标注偏离
- **商务条款**：用商务响应表逐条应答
- **方案类要求**：在对应章节先引用需求，再展开方案
- **格式要求**：按招标给定格式填写，不改变表格结构

### 3.3 应答禁忌

- ❌ 笼统写"完全响应招标文件所有要求"而无逐条对应
- ❌ 抄录招标要求后不写具体方案
- ❌ 漏答带 ★/▲ 的实质性条款
- ❌ 负偏离不说明、不提示
- ❌ 应答位置与偏离表标注的章节不一致

### 3.4 偏离处理

- 无偏离：明确写"完全满足""无偏离"
- 正偏离：写明优于要求的具体指标，作为得分点
- 负偏离：
  - 实质性条款（★/▲/废标条款）负偏离 → **立即提示用户**：此条负偏离可能导致废标，建议调整或放弃
  - 非实质性条款负偏离 → 在偏离表中如实填写，说明原因与替代措施

## 四、占位符规范

### 4.1 统一格式

所有需要用户填写、后补或确认的内容，使用**中文方括号占位符**：

```
【投标单位名称】
【项目编号】
【投标日期：YYYY年MM月DD日】
【报价金额（大写）】
【报价金额（小写：￥000,000.00）】
【待补充：营业执照副本复印件（加盖公章）】
【待补充：项目经理注册建造师证书编号】
【待补充：近3年类似项目业绩表（附合同复印件）】
```

### 4.2 占位符类型

| 类型 | 格式 | 示例 |
|------|------|------|
| 主体信息 | 【名称】 | 【投标单位名称】 |
| 日期 | 【日期：格式】 | 【投标日期：YYYY年MM月DD日】 |
| 金额 | 【金额（大写/小写）】 | 【报价金额（大写）】 |
| 待补充材料 | 【待补充：材料名】 | 【待补充：ISO 9001 证书复印件】 |
| 签字盖章 | 【签字/盖章位置】 | （加盖投标人公章） |

### 4.3 禁止

- 不用 `xxx`、`XXX`、`TODO`、`待填`、`???` 等不可检索的占位
- 不在正文遗留"此处略""详见附件"而无实际内容或占位
- 待补充材料在文末**汇总成清单**，便于用户一次性备齐

---

## 五、签字盖章规范

以下位置通常需要签字盖章（以招标文件为准）：

- 封面：投标人公章
- 投标函：投标人公章 + 法定代表人或授权代表签字/盖章
- 授权委托书：投标人公章 + 法定代表人签字 + 授权代表签字
- 开标一览表：投标人公章
- 报价表：投标人公章
- 偏离表：投标人公章
- 所有复印件：加盖公章
- 骑缝章（如有要求）：整本骑缝
- 电子版：CA 签章（电子招投标项目）

在 Markdown 中用文字标注：`（加盖投标人公章）`、`（法定代表人签字）`。

---

## 六、报价编写规范

1. 开标一览表、投标函、分项报价表三处总报价**必须一致**
2. 大写金额规范："人民币壹佰贰拾叁万肆仟伍佰陆拾柒元捌角玖分"，末尾加"整"（无角分时）
3. 小写金额前加"￥"，保留两位小数，千分位
4. 分项合计 = 总价，税率明确
5. 报价范围说明清晰（含/不含税、含/不含运保、含/不含安装培训）
6. **不杜撰具体报价**：用户未给金额时一律用占位符，只提供计算结构
7. 若设最高限价，报价不得超过（提示用户核算）

## 七、自检清单

### 7.1 完整性

- [ ] 商务标、技术标、报价标三册齐全（或按招标要求的分册）
- [ ] 封面、目录、页码齐全
- [ ] 投标函、开标一览表、授权委托书、偏离表、报价表等关键表单齐全
- [ ] 资格证明文件清单中每项都有材料或占位符
- [ ] 招标文件要求的所有附件、声明、承诺函已包含

### 7.2 响应性（模式 A 重点）

- [ ] 所有 ★/▲/加粗实质性条款已逐条应答且为"满足"
- [ ] 所有技术参数已在技术响应表中逐条对应
- [ ] 所有商务条款已在商务响应表中逐条应答
- [ ] 否决项（废标条款）全部规避
- [ ] 投标有效期、工期/交货期、质保期、付款方式满足招标要求
- [ ] 报价未超最高限价/预算
- [ ] 投标保证金金额、形式、到账时间符合要求
- [ ] 正偏离已主动声明；负偏离已如实填写并提示风险
- [ ] 应答位置与偏离表标注章节一致

### 7.3 一致性

- [ ] 项目名称、编号、采购人名称在全文一致（与招标文件一致）
- [ ] 投标人名称全文一致（与营业执照一致）
- [ ] 三处总报价（投标函/开标一览表/分项合计）一致
- [ ] 报价大小写一致
- [ ] 工期/交货期/质保期在投标函、附录、响应表中一致
- [ ] 目录标题、页码与正文一致
- [ ] 人员姓名、证书编号在简历、证书、社保中一致

### 7.4 规范与风险

- [ ] 无杜撰的资质、业绩、人员、财务数据
- [ ] 所有待补充内容使用规范占位符
- [ ] 文末附"待补充材料清单"
- [ ] 签字盖章位置已标注
- [ ] 无模糊措辞、无贬低竞争对手、无违规承诺
- [ ] 术语统一、人称统一
- [ ] 排版符合招标格式要求（或 [format-spec.md](format-spec.md) 默认规范）
- [ ] 暗标项目：无单位名称/Logo/页眉页脚/页码等任何标识性内容，暗标格式核对表逐条通过
- [ ] 目录与招标文件格式章节逐条比对一致（模式 A）或已经用户确认（模式 B），详见 [toc-construction.md](toc-construction.md)
- [ ] 已提示用户：最终报价、资质材料、签字盖章需由投标方确认后提交

### 7.5 交付确认

- [ ] 已向用户说明工作模式（招标驱动/标准兜底/混合）
- [ ] 招标关键信息已经用户确认（模式 A）
- [ ] 输出自检结果清单
- [ ] 提示用户本文件为 AI 辅助生成，提交前须人工复核
