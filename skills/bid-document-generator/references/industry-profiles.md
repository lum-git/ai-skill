# 行业投标画像

不同行业的投标文件在章节侧重、资格要求、技术方案重点上差异明显。本文件给出常见行业的画像，用于"标准兜底模式"下调整章节比重，以及"招标驱动模式"下预判必备内容。

> 行业判定基于项目名称、采购内容关键词。同一项目可能跨多个画像（如"智慧园区信息化"同时涉及 IT 信息化与弱电工程），以主采购内容为准，融合相关画像。

---

## 一、IT / 信息化类

**适用**：软件开发、系统集成、应用平台建设、数据中心、云服务、智慧XX、网站/APP、运维服务。

### 1.1 典型关键词

信息化、系统、平台、软件、开发、集成、数据、云、智慧、数字化、运维、等保、大数据、人工智能。

### 1.2 重点章节

- 项目理解与需求分析（重点：业务理解）
- 总体技术方案（架构图、技术栈、关键技术）
- 功能方案（模块逐项说明，配原型/流程图）
- 数据方案（数据架构、数据迁移、数据治理）
- 接口与集成方案
- 安全方案（等保 2.0 对应级别、密评）
- 实施方案（开发方法论、里程碑、交付物）
- 测试方案
- 运维与售后服务
- 培训方案

### 1.3 常见资格要求

- 软件企业证书 / 高新技术企业
- ISO 9001 / ISO 27001 / ISO 20000 / CMMI
- 系统集成资质（已取消国家级，看项目特定要求）
- 信息安全服务资质（安全工程类 / 风险评估 / 应急处理）
- 涉密信息系统集成资质（涉密项目）
- 软件产品登记、著作权
- 项目经理（PMP/软考高级/信息系统项目管理师）
- 类似项目业绩

### 1.4 技术方案要点

- 架构图：业务架构、应用架构、数据架构、技术架构、部署架构
- 非功能需求：性能（并发、响应时间）、可用性（SLA）、可扩展性、兼容性、安全
- 国产化适配（信创）：CPU、OS、数据库、中间件兼容性（如要求）
- 等保级别与对应措施
- 源代码/知识产权归属
- 数据迁移策略与回滚

### 1.5 报价构成

软件许可、定制开发人月、硬件、系统集成、实施、培训、首年运维、税费。

## 二、工程建设类

**适用**：房屋建筑、市政、公路、水利、安装、装饰装修、园林绿化、弱电/机电安装。

### 2.1 典型关键词

工程、施工、建设、土建、安装、市政、道路、桥梁、装修、幕墙、机电、消防、弱电、智能化、EPC、总承包。

### 2.2 重点章节

- 施工组织设计（核心，通常占技术标最大篇幅）
  - 工程概况、施工部署、施工方案/方法
  - 施工进度计划（横道图/网络图）及保证措施
  - 资源投入（劳动力、材料、机械设备）
  - 施工总平面布置
- 质量保证措施
- 安全生产保证措施
- 文明施工、环境保护措施
- 工期保证措施
- 项目管理机构（项目经理、技术负责人、五大员）
- 重点难点分部分项方案（深基坑、高支模、起重吊装等需专项方案）
- 季节性施工措施（雨季/冬季）

### 2.3 常见资格要求

- 建筑业企业资质（施工总承包/专业承包序列及等级）
- 安全生产许可证
- 项目经理：注册建造师（专业/级别对应）+ 安全生产考核合格证 B 证
- 技术负责人职称
- 五大员（施工员、质量员、安全员、材料员、资料员）上岗证
- 类似工程业绩（规模/金额）
- 财务要求（净资产、流动资金）

### 2.4 技术方案要点

- 严格响应工程量清单、图纸、技术规范
- 涉及危险性较大的分部分项工程须列专项方案
- 施工进度网络图关键线路清晰
- 平面布置合理（临建、道路、材料堆场、塔吊覆盖）
- 质量目标与验收标准（合格/优良，对应规范）
- 安全事故应急预案

### 2.5 报价构成

分部分项工程费、措施项目费、其他项目费、规费、税金。工程量清单计价，不允许擅自修改清单量。

## 三、货物采购类

**适用**：设备、材料、产品、家具、车辆、医疗器械、家电、办公设备采购。

### 3.1 典型关键词

采购、供货、设备、产品、材料、家具、车辆、医疗器械、实验室设备、空调、电梯。

### 3.2 重点章节

- 技术参数响应/偏离表（核心，逐条响应）
- 产品配置清单与选型说明
- 产品技术方案（原理、结构、性能）
- 产品检测报告、认证证书
- 生产制造与供货方案
- 包装、运输、装卸方案
- 安装调试方案
- 验收方案
- 培训方案
- 质保与售后服务（重点）
- 备品备件

### 3.3 常见资格要求

- 制造商授权书（代理商投标时）
- 生产许可证 / 3C 认证 / 医疗器械注册证 / 特种设备制造许可
- ISO 9001 / ISO 14001 / ISO 45001
- 产品检测报告（权威机构）
- 环保/节能产品认证（政府采购强制/优先采购）
- 类似供货业绩

### 3.4 技术方案要点

- 技术参数表必须与招标规格逐条对应，注明"完全满足/正偏离"
- 提供产品彩页、说明书、检测报告页码索引
- 节能产品、环境标志产品在政府采购中享优惠
- 进口产品须有进口审批且明确原产地
- 交货期、运输方式、保险

### 3.5 报价构成

设备单价、数量、辅料、运输、保险、安装调试、培训、税费、质保。

## 四、服务类

**适用**：IT 运维、物业管理、物流、保洁、安保、餐饮、咨询、设计、监理、审计、培训、会展、租赁。

### 4.1 典型关键词

服务、运维、运营、物业、物流、保洁、保安、咨询、设计、监理、审计、评估、培训、外包。

### 4.2 重点章节

- 服务需求理解
- 服务总体方案
- 服务内容与标准（量化 SLA）
- 服务团队配置（人员简历、上岗证、人数）
- 服务流程与管理制度
- 服务质量保障措施
- 应急响应方案
- 人员管理（招聘、培训、考核、排班）
- 设备/工具投入
- 安全/保密措施
- 服务承诺与考核

### 4.3 常见资格要求

- 行业服务资质（物业资质、保安服务许可证、道路运输许可等）
- ISO 体系认证
- 人员持证上岗（具体工种证书）
- 类似服务业绩

### 4.4 技术方案要点

- 服务标准尽量量化（响应时间、到场时间、处理时效、可用率）
- 人员配置表（岗位、人数、班次、证书）
- 针对服务场景的应急预案
- 考核与奖惩机制（与费用挂钩）

### 4.5 报价构成

人月/人天单价 × 投入量、管理费、工具设备、税费、不可预见费。

## 五、其他常见类型

### 5.1 设计类（勘察/设计/规划）

- 重点：设计理念、设计方案、效果图、设计团队、类似设计业绩
- 人员：注册建筑师/结构师/规划师、各专业负责人
- 报价：设计费按《工程勘察设计收费标准》或市场价

### 5.2 监理类

- 重点：监理大纲、监理机构、三控三管一协调、监理制度
- 人员：总监理工程师（注册监理工程师）、专业监理工程师
- 报价：监理费按发改价格〔2007〕670 号或市场调节

### 5.3 EPC / 工程总承包

- 同时覆盖设计 + 采购 + 施工，融合工程类与货物类要点
- 重点：设计方案、设备选型、施工组织、总进度协调、限额设计
- 资格：设计资质 + 施工资质（或联合体）、工程总承包业绩

### 5.4 PPP / 特许经营

- 重点：融资方案、运营方案、回报机制、风险分担、财务测算
- 通常涉及法律方案、项目公司架构、合作协议响应

## 六、行业画像选择决策

```
项目是否涉及"施工/建设/土建/安装"？
├─ 是 → 工程建设类（若同时含设备采购，融合货物类；若含设计，考虑 EPC）
└─ 否
   ├─ 是否涉及"设备/产品/材料供货"为主？
   │  └─ 是 → 货物采购类
   ├─ 是否涉及"系统/平台/软件开发/集成/数据"？
   │  └─ 是 → IT/信息化类
   ├─ 是否以"运维/物业/咨询/培训/物流"等人力服务为主？
   │  └─ 是 → 服务类
   └─ 其他 → 按通用结构，根据具体内容调整
```

> 选定主画像后，对应画像的重点章节必须充分展开；非相关章节可合并或简化。
