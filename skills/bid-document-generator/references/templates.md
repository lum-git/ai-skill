# 关键章节模板片段

本文件提供投标文件高频文书的可复用模板。使用时将占位符替换为实际内容；招标文件提供了固定格式的，**以招标文件格式为准，本文件仅作兜底**。

> 占位符规则见 [writing-guidelines.md](writing-guidelines.md#四占位符规范)。签字盖章处以文字标注。

---

## 一、投标函

```
投 标 函

致：【采购单位名称】（【采购代理机构名称】）

根据贵方【项目名称】（项目编号：【项目编号】）的招标文件，我方经研究上述招标文件的全部内容后，愿以如下投标总报价承担本项目：

投标总报价（大写）：人民币【报价金额（大写）】
投标总报价（小写）：￥【报价金额（小写：000,000.00）】

并郑重承诺如下：

1. 工期/交货期/服务期：【     】，自合同签订之日起计算。
2. 质量标准：【符合/达到     标准，一次验收合格】。
3. 质保期：【     】，自验收合格之日起计算。
4. 投标有效期：自投标截止之日起【 90 】日历天。
5. 我方同意按招标文件规定提交投标保证金，并遵守招标文件中关于投标人的全部要求。
6. 若我方中标，将按招标文件规定与贵方签订合同，按期足额提交履约保证金，并严格履行合同责任。
7. 我方承诺所提供的全部投标资料真实、合法、有效，如有虚假，愿承担相应法律责任。
8. 我方理解贵方不一定接受最低报价的投标，也不解释中标或未中标原因。

投标人：【投标单位名称】（加盖投标人公章）

## 五、商务条款响应/偏离表

```
商务条款响应/偏离表

项目名称：【项目名称】          项目编号：【项目编号】

| 序号 | 招标文件条款号 | 招标文件商务要求 | 投标响应内容 | 偏离情况 | 备注 |
|------|---------------|-----------------|-------------|---------|------|
| 1 |  | 投标有效期：90 日历天 | 承诺 90 日历天 | 无偏离 |  |
| 2 |  | 工期：【 】日历天 | 承诺【 】日历天 | 无偏离 |  |
| 3 |  | 质保期：【 】年 | 承诺【 】年 | 无偏离 |  |
| 4 |  | 付款方式：【 】 | 【完全响应 / 具体说明】 | 无/正/负偏离 |  |
| 5 |  | 履约保证金：合同价【 】% | 承诺按招标文件提交 | 无偏离 |  |
| 6 |  | 验收标准：【 】 | 完全响应 | 无偏离 |  |
| 7 |  | 售后服务响应：【 】小时到场 | 承诺【 】小时到场 | 无/正偏离 |  |
| 8 |  | 培训：【 】 | 【     】 | 无偏离 |  |

1. "偏离情况"栏填写：无偏离 / 正偏离 / 负偏离；
2. 负偏离须在备注中说明原因及替代措施；

## 十一、中小企业声明函（服务类示例）

```
中小企业声明函（工程、服务）

本公司（联合体）郑重声明，根据《政府采购促进中小企业发展管理办法》
（财库﹝2020﹞46 号）的规定，本公司（联合体）参加【采购单位名称】的
【项目名称】采购活动，提供的服务全部由符合政策要求的中小企业承接。
相关企业（含联合体中的中小企业、签订分包意向协议的中小企业）的具体情况如下：

1. 【项目名称】，属于【信息传输业/软件和信息技术服务业/建筑业/其他】；
   承建（承接）企业为【投标单位名称】，从业人员【 】人，营业收入为【 】万元，
   资产总额为【 】万元，属于【中型企业/小型企业/微型企业】。

以上企业，不属于大企业的分支机构，不存在控股股东为大企业的情形，
也不存在与大企业的负责人为同一人的情形。

本企业对上述声明内容的真实性负责。如有虚假，将依法承担相应责任。

投标人：【投标单位名称】（加盖投标人公章）
日期：【     】
```

> 货物类声明函格式略有不同（需注明制造商及所属行业），以招标文件附件格式为准。从业人员/营收/资产以工信部联企业〔2011〕300 号划型标准为依据，由用户据实填写。
