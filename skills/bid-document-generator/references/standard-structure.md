# 投标文件章节要素库

投标文件目录**没有法定统一结构**。本文件是**章节素材库**，不是目录模板，不得整表照抄：

- **有招标文件**：目录一律以招标文件"投标文件组成/投标文件格式"章节为准，**逐字照抄**（流程见 [toc-construction.md](toc-construction.md)），本文件的固定结构不适用
- **无招标文件**：按 [toc-construction.md](toc-construction.md) 第四章的内容推导流程，**根据用户提供的采购内容 + 行业画像**从本要素库中选取、增删、组装目录，经用户确认后生成

要素库基于《政府采购法》《招标投标法》及行业惯例，覆盖绝大多数货物、服务、工程类投标的通用章节。

> ⚠️ 无招标文件时，在文件开头注明："本文件按行业通用标准编制，具体条款、格式、装订要求以最终招标文件为准。" 具体数值（金额、日期、证书号等）用占位符，不杜撰。

## 二、封面与目录

### 封面要素

- 项目名称
- 项目编号（如有）
- 标段/包号（如有）
- "投标文件"字样
- 投标人名称（公章位置）
- 法定代表人或授权代表（签字位置）
- 投标日期

### 目录

- 自动生成，层级到三级标题
- 标注页码
- 三标分册时每册独立目录

## 三、商务标各章编写要点

### 1. 投标函

- 致：采购人/招标代理
- 明确投标项目、编号、标段
- 投标总报价（大小写）
- 工期/交货期/服务期承诺
- 投标有效期承诺
- 质量目标承诺
- 售后服务承诺
- 声明如中标将签合同、提交履约保证金
- 投标人盖章、法定代表人或授权代表签字、日期
- 模板见 [templates.md](templates.md#一投标函)

### 2. 投标函附录

对关键商务承诺以表格形式列明：

| 序号 | 条款内容 | 约定 |
|------|---------|------|
| 1 | 投标报价 | |
| 2 | 工期/交货期/服务期 | |
| 3 | 投标有效期 | |
| 4 | 质量标准 | |
| 5 | 质保期 | |
| 6 | 履约保证金 | |
| 7 | 付款方式 | |

### 3. 法定代表人身份证明

- 姓名、性别、职务、身份证号
- 证明其为投标人法定代表人
- 附身份证复印件（正反面）
- 投标人盖章、日期

### 4. 授权委托书

- 授权代表姓名、职务、身份证号
- 授权范围（签署/澄清/递交/签订合同等）
- 授权期限
- 附法定代表人与授权代表身份证复印件
- 法定代表人签字、投标人盖章、日期

### 5. 投标保证金

- 交纳凭证复印件（银行回单/保函/担保）
- 金额、形式、到账时间
- 退还账户信息

### 6. 资格证明文件

按以下顺序排列，复印件加盖公章：

- 营业执照（副本）
- 相关行业资质证书
- 近 N 年财务审计报告或银行资信证明
- 依法缴纳税收证明（近 N 月）
- 社会保障资金缴纳证明（近 N 月）
- 近 N 年无重大违法记录声明
- "信用中国"查询截图（失信被执行人、税收违法、政府采购严重违法失信）
- 特定行业准入证书
- 中小企业声明函（如适用，享受价格扣除）

### 7. 商务条款响应/偏离表

逐条响应招标商务要求（无招标时按行业惯例列通用条款）：

| 序号 | 招标/商务条款 | 投标响应 | 偏离 |
|------|-------------|---------|------|
| 1 | 工期 | | 无 |
| 2 | 付款方式 | | 无 |
| 3 | 质保期 | | 无 |
| ... | | | |

### 8. 投标人概况

- 企业简介（成立时间、注册资本、性质、注册地、经营范围、员工规模）
- 组织架构
- 主营业务与核心能力
- 主要客户
- 资质荣誉
- 财务数据（近 3 年营业收入、利润、资产负债率，用占位符）

### 9. 近年类似项目业绩

- 业绩清单表（项目名称、采购人、合同金额、签订时间、项目内容、联系人）
- 每个业绩附合同关键页复印件（封面、金额、签字盖章页）
- 按时间倒序，优先放与本项目相似的业绩
- 数量与金额按评分标准准备（无招标时准备 3~5 个）

### 10. 项目管理机构与人员

- 项目组织架构图
- 项目经理：简历、资格证书、类似业绩、社保
- 技术负责人：简历、证书
- 核心团队成员：岗位、职责、资历
- 人员到岗承诺

### 11. 信誉与承诺

- 无重大违法记录声明
- 无行贿犯罪记录声明（或承诺函）
- 不转包/不分包承诺（或分包说明）
- 保密承诺
- 廉洁承诺
- 知识产权承诺
- 真实性声明

## 四、技术标各章编写要点

### 1. 项目理解与需求分析

- 项目背景理解
- 建设目标理解
- 现状与痛点分析
- 需求理解（功能/性能/业务）
- 项目重点、难点分析及对策

### 2. 总体技术方案

- 设计原则（先进性、成熟性、安全性、可扩展性、经济性）
- 总体架构（逻辑架构、技术架构、部署架构）
- 技术路线选型（关键技术、框架、中间件）
- 方案特点与优势
- 货物类：产品选型、配置说明、技术参数响应表

### 3. 技术参数响应/偏离表（货物类重点）

逐条对照设备/软件技术参数：

| 序号 | 招标技术参数 | 投标产品参数 | 偏离 | 证明材料页 |
|------|-------------|-------------|------|-----------|

> 服务/工程类此章可并入总体方案。

### 4. 项目实施方案

- 实施阶段划分（准备、设计、开发/采购、实施、测试、试运行、验收）
- 各阶段工作内容、交付物、责任人
- 建设/施工/供货方案
- 现场组织管理
- 接口管理与协调

### 5. 项目组织与进度计划

- 项目组织机构
- 进度计划（总工期、里程碑、横道图/网络图）
- 进度保障措施
- 资源投入计划（人力、设备）

### 6. 质量保障体系

- 质量目标
- 质量管理体系（ISO 9001 等）
- 质量控制措施（设计/采购/施工/测试各环节）
- 测试与验收方案
- 质量通病预防

### 7. 安全与文明生产/环保措施

- 工程类：安全生产责任制、安全防护、应急预案、文明施工
- IT/服务类：信息安全、数据安全、等保/密评落实
- 环保措施、绿色施工（如适用）

### 8. 培训方案

- 培训目标
- 培训对象与内容
- 培训方式、课时、地点
- 培训师资
- 培训教材与考核
- 培训计划安排

### 9. 售后服务与运维方案

- 服务体系（服务网点、热线）
- 质保期服务内容
- 响应时间（接报响应、到场、解决）
- 巡检与预防性维护
- 备品备件
- 运维团队
- 质保期后服务方案（费用优惠）

### 10. 技术偏离表

| 序号 | 招标技术条款 | 投标响应 | 偏离情况 | 说明 |
|------|-------------|---------|---------|------|

### 11. 风险分析与应对

- 进度风险、技术风险、管理风险、外部风险
- 识别 → 评估 → 应对措施 → 责任人

## 五、报价标各章编写要点

### 1. 开标一览表

| 项目名称 | 投标总报价（小写） | 投标总报价（大写） | 工期/交货期 | 质保期 | 投标有效期 |
|---------|-------------------|-------------------|------------|--------|-----------|

> 开标一览表是唱标依据，必须与投标函报价完全一致。

### 2. 分项报价明细表

按项目类型选择表式：

- **货物类**：设备名称、品牌、规格型号、数量、单位、单价、总价、产地
- **工程类**：分部分项工程量清单计价（参照工程量清单）
- **服务类**：人月单价、人员级别、投入人月、各项费用
- **IT 集成类**：硬件、软件、开发实施、集成、培训、运维分别列项
- 含税总价、税率

### 3. 报价说明

- 报价包含范围（设备、运输、安装、调试、培训、税费、质保等）
- 报价依据
- 优惠条件（如有）
- 价格调整说明（合同期内是否固定）

### 4. 中小企业声明函（如适用）

- 声明企业类型（中型/小型/微型）
- 从业人员、营业收入、资产总额
- 所属行业
- 制造商/服务商信息（工程/货物/服务）
- 投标人盖章、日期

## 六、章节取舍原则

- **货物采购类**：技术参数响应表、产品配置、供货运输安装是重点；弱化"开发实施方案"
- **工程建设类**：施工组织设计、进度、安全质量、项目班子是重点
- **服务类（运维/咨询/物业）**：服务方案、人员配置、服务流程、应急是重点；无设备参数表
- **IT 信息化类**：架构、功能、实施、数据迁移、等保、运维是重点
- 具体差异见 [industry-profiles.md](industry-profiles.md)
