# 招标文件解析规范

本文件定义"招标驱动模式"下，如何解析招标文件、提取关键信息、建立合规矩阵、识别否决项。

---

## 一、信息提取清单

解析招标文件时，按以下分类逐项提取。**原文优先**：能摘录原文的，保留条款编号与原文，避免转述失真。

### 1.1 项目基础信息

| 字段 | 说明 | 来源位置 |
|------|------|---------|
| 项目名称 | 完整全称（与封面一致） | 招标公告/封面 |
| 项目编号/招标编号 | 完整编号 | 封面/公告 |
| 采购人/招标人 | 全称 | 公告 |
| 采购代理机构 | 若有 | 公告 |
| 预算金额/最高限价 | 含大小写、是否设上限 | 公告/采购需求 |
| 采购方式 | 公开招标/邀请招标/竞争性谈判/磋商/询价 | 公告 |
| 投标截止时间 | 精确到分钟 | 公告 |
| 开标时间/地点 | | 公告 |
| 投标有效期 | 通常 90 天，自投标截止日起 | 投标人须知 |
| 是否接受联合体 | 是/否；若接受，联合体要求 | 投标人须知 |
| 是否专门面向中小企业 | 是/否；预留比例/价格扣除比例 | 公告/资格要求 |
| 评标办法 | 综合评分法/最低评标价法/经评审的最低投标价法 | 评标办法 |
| 标书售价 | | 公告 |
| 投标保证金 | 金额、形式、到账截止时间、账户 | 投标人须知 |
| 履约保证金 | 比例、形式 | 合同条款 |
| 付款方式 | 预付款/进度款/验收款/质保金比例 | 合同条款/采购需求 |

### 1.2 资格要求

逐条列出，标注是否为"资格性审查项"（不满足即废标）：

- 营业执照（经营范围要求）
- 行业资质证书（如系统集成、建筑施工资质、安防资质、ISO 体系等）及等级
- 财务要求（近 N 年财务审计报告、无亏损、净资产额）
- 业绩要求（近 N 年类似项目合同数量/金额）
- 人员要求（项目经理资格、技术负责人、团队配置及证书）
- 信誉要求：
  - 未被列入"信用中国"失信被执行人/重大税收违法/政府采购严重违法失信名单
  - 近 N 年无重大违法记录声明
  - 无行贿犯罪记录（中国裁判文书网查询）
- 特定行业准入（如涉密、安防工程企业资质、医疗器械经营许可等）
- 中小企业声明函（若面向中小企业或享受价格扣除）

### 1.3 实质性要求（重点）

招标文件中以下标记通常表示**不可偏离的实质性要求**，必须逐条满足：

- 条款前带 **★**、**▲**、**●**、**■** 等符号
- 文字标注"必须""应当""强制""实质性要求""不可偏离""不接受负偏离"
- **加粗**或下划线强调的条款
- 明确写"不满足作无效投标处理"的条款

提取时记录：条款编号、原文、所在章节、要求类型（资格/商务/技术）、应答位置。

### 1.4 否决项（废标条款）

专门搜索并汇总"无效投标""废标""否决投标""拒收"相关条款，典型包括：

- 逾期送达/未送达指定地点
- 未按规定密封、签章
- 不满足资格要求
- 报价超过预算/最高限价
- 投标有效期不足
- 附有招标人不能接受的条件
- 明显不符合技术规格、技术标准
- 出现串通投标、弄虚作假
- 未提交投标保证金或金额不足
- 关键条款负偏离

> 否决项清单是自检的核心依据，必须单独成表。

### 1.5 商务要求

- 交货期/工期/服务期及起始计算方式
- 交货/服务地点
- 质保期/缺陷责任期
- 验收标准与程序
- 付款条件与比例
- 培训要求
- 售后服务响应时间、到场时间
- 保险要求
- 知识产权归属
- 保密要求

### 1.6 技术要求

- 项目概述、建设目标、建设内容范围
- 功能需求清单（逐条）
- 性能指标（并发数、响应时间、吞吐量、容量等）
- 技术参数表（设备/软件规格、型号、数量）
- 技术标准/规范遵循
- 接口要求、兼容性要求
- 部署环境、软硬件清单
- 安全等保/密评要求
- 交付物清单

### 1.7 评分标准（综合评分法）

按"价格分 / 技术分 / 商务分"三类提取：

| 评分项 | 分值 | 评分细则 | 我方准备材料 |
|--------|------|---------|-------------|
| 报价 | xx | 低价优先法公式 | 报价 |
| 技术方案 | xx | 方案完整性、先进性… | 技术标对应章节 |
| 业绩 | xx | 近 N 年每个合同 x 分，满分 x 分 | 合同复印件+清单 |
| 人员 | xx | 项目经理/团队证书 | 证书+社保 |
| 售后 | xx | 响应时间、质保期延长 | 承诺函 |
| 培训 | xx | 培训计划、人次 | 培训方案 |
| 资质认证 | xx | ISO/行业资质 | 证书 |

> 评分标准决定标书内容的侧重——高分值项要写厚写透，低分项不浪费篇幅。

### 1.8 格式与装订要求

- 正本、副本份数；电子版（U 盘/光盘）份数与格式
- 签字盖章要求：哪些页必须签字、哪些必须盖公章、是否要求骑缝章
- 封装要求：外层封套格式、"开标前不得启封"字样
- 目录、页码、连续页码要求
- 字体、字号、行距、纸张、打印单面/双面要求
- 是否提供投标文件格式模板（附件）

## 二、合规矩阵（应答对照表）

### 2.1 矩阵结构

对所有实质性要求、技术参数、商务条款建立统一矩阵：

| 序号 | 招标条款号 | 招标要求原文 | 要求类别 | 投标应答摘要 | 偏离情况 | 应答章节 |
|------|-----------|-------------|---------|-------------|---------|---------|
| 1 | 第三章 3.1 | 系统支持≥1000 并发… | 技术参数 | 支持 2000 并发，满足 | 正偏离 | 技术标 4.2 |
| 2 | 第三章 3.2 | 响应时间≤2s | 技术参数 | 平均 1.2s | 正偏离 | 技术标 4.2 |
| 3 | 第二章 2.4 | 质保期 3 年 | 商务 | 承诺 3 年 | 无偏离 | 商务标 6 |

### 2.2 偏离判定

- **无偏离**：完全满足
- **正偏离**：优于招标要求（主动声明，作为得分点）
- **负偏离**：低于招标要求（必须显式说明并提示风险；实质性条款负偏离可能废标）

### 2.3 使用方式

1. 该矩阵在编写阶段是**写作大纲**，确保每条要求都有应答位置
2. 成文后演化为正文中的两张表：
   - **商务条款响应/偏离表**（商务标）
   - **技术条款响应/偏离表**（技术标）
3. 若招标文件指定了偏离表格式，**严格使用其格式**

## 三、招标信息摘要模板

解析完成后，向用户输出以下摘要确认后再动笔：

```
【招标文件关键信息摘要】
项目名称：
项目编号：
采购人：
预算/最高限价：
投标截止：
投标有效期：
投标保证金：
评标办法：
资格要求（关键）：
实质性条款数量：共 N 条（★x / ▲x / 加粗x）
否决项：共 N 条，详见清单
商务关键：工期/交货期、质保期、付款
技术关键：（列 3~5 条核心指标）
评分权重：价格 N% / 技术 N% / 商务 N%
格式要求：正本x 副本x 电子版x
待澄清/疑似矛盾：（如有）
```

## 四、常见招标文件结构（供定位参考）

不同招标文件章节顺序略有差异，典型结构：

1. 招标公告（投标邀请书）
2. 投标人须知（前附表 + 正文）
3. 评标办法
4. 合同条款及格式
5. 采购需求/技术规格/工程量清单
6. 投标文件格式（附件）

> **第 6 部分"投标文件格式"是标书目录的第一依据**，其中通常包含：投标函、开标一览表、法定代表人身份证明、授权委托书、资格证明文件、报价表、偏离表、中小企业声明函等格式。优先复用这些格式。
