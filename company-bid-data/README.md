# 公司投标固定资料库

> 本目录存放**跨项目复用的公司固定资料**，供 `bid-document-generator` 技能在生成标书时自动引用。
>
> ⚠️ **本目录包含敏感/私有资料（执照、合同、证书、签章等），已通过 `.gitignore` 排除，不纳入版本控制。** 仅 README.md 索引文件入库。

---

## 三、使用方式

1. **首次使用**：把公司现有资料按目录归类放入，填写上方清单表。
2. **每次投标**：AI 会自动读取本 README 的清单和 `01~08` 目录中的文件，把能直接用的内容（公司简介、资质、业绩、人员）填入标书对应章节；扫描件在标书中以"【待插入：xx 证书复印件】"占位，并在文末"待补充材料清单"中列出。
3. **更新资料**：资质到期换证、新增业绩、人员变动时，替换文件并更新本 README 清单表即可，所有后续标书自动用新资料。
4. **多公司/多主体**：如果有多个投标主体，在 `company-bid-data/` 的同级建 `company-bid-data-<主体名>/`，并在生成时告知 AI 使用哪个主体。

## 四、隐私与安全

- 本目录除 README.md 外，**所有文件不提交 git**（见同级 `.gitignore`）
- 签章素材（公章/签字 PNG）仅限授权人员用于电子投标，不得外传
- 纸质复印件用于标书装订时，仍需加盖鲜章
- 若 skill 仓库被分享或同步到外部，**先确认本目录未被打包**
